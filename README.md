# 지오의 블록 대탈출 🎂

지오의 중1 생일을 위한 브라우저 미니게임 선물입니다.

마인크래프트 블록 그래픽 + 로블록스식 장애물 코스(옵비) 느낌의 러너 게임으로,
크리퍼와 용암 구덩이를 점프로 피하고 다이아몬드/골드를 모아 레벨업하면서
끝에 있는 생일 케이크까지 도달하면 승리합니다.

## 실행 방법

인터넷 연결이나 별도 설치 없이 `HappyBirthdayGio.html` 파일 하나만 있으면 됩니다.

- 그냥 `HappyBirthdayGio.html`을 더블클릭해서 브라우저로 열면 바로 플레이할 수 있어요.
- 또는 이 폴더에서 `python3 -m http.server`를 실행하고 브라우저로 접속해도 됩니다.

## 조작법

- PC: `Space` / `↑` / `W` 키로 점프
- 모바일: 화면 탭으로 점프

## 특징

- 하트 4개, 레벨업 시스템, 골드/다이아 수집, 진행도 표시
- 승리 시 색종이(컨페티) 애니메이션과 지오를 위한 생일 메시지
